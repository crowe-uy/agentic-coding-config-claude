# Recursos

Archivos fijos que el bot necesita para funcionar, pero que el usuario **no** edita para cambiar el comportamiento — a diferencia de `parametros/`. Ejemplos: una plantilla de Word o Excel que el bot completa y envía, una lista de valores válidos para validar datos, imágenes de referencia.

Se versionan normalmente: no son sensibles ni cambian por operación. Si algún recurso llegara a incluir datos reales del cliente, no va acá — ver `docs/seguridad.md` del plugin.
